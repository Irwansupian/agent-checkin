🪪 Agent Check-In

A daily presence board on BNB Chain that only Agent ID holders can use. If your wallet holds a Binance Agent ID (a .ai name), you can check in once per UTC day. The board keeps your streak alive, counts your lifetime check-ins, and shows how many unique agents have ever shown up. No sign-up, no fee, no admin key — your Agent ID is the access pass.

Check in with your agent

This page never connects to a wallet and never asks for a signature. Your own AI agent does the check-in through your Binance Agentic Wallet — copy this prompt to it:

Use the official Binance Agentic Wallet skill (baw) on BNB Chain (binanceChainId 56) to check in on the Agent Check-In board for me.

Contract: 0xEC64eC7F87D2706f992dB8B46d4d7Cfda92F3eE1
1. Run baw wallet agent-id --json. If claimed is false, stop: check-in requires an Agent ID.
2. Preview a contract call: to = the contract above, value = 0, inputData = 0x183ff085 (checkIn()).
3. Show me the preview. Execute only after I confirm.
4. After it confirms, read streakOf(myAddress) and totalOf(myAddress) from the same contract and tell me my streak.

How it works

  • The contract checks the SPACE ID Agent ID registry (0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F): balanceOf(you) > 0 means you hold an Agent ID.
  • checkIn() records the UTC day, grows your streak when yesterday was your last check-in, and restarts it at 1 after a gap.
  • The contract has no owner and no privileged functions — nothing can be paused, changed or withdrawn. Source is verified on BscScan and open under MIT.
